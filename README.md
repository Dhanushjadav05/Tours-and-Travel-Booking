Tours & Travels Booking Web App

This is a dynamic web application built using Python (Flask), HTML, CSS, and JavaScript, with MySQL to store booking data. The platform allows users to select tours, calculate total prices based on the number of passengers, and interact with different payment options. It provides real-time updates and a responsive interface for a smooth booking experience. The application is deployed locally and can be accessed publicly via VS Code port forwarding, making it easy to demo and test the system.
